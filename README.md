# SPLIT / RUN

Standalone React/Vite version of the supplied hybrid strength + conditioning tracker.

## Run locally

1. Install Node.js 18+.
2. In this folder run:
   `npm install`
3. Start it:
   `npm run dev`
4. Open the local address Vite prints.

## Build a production version

`npm run build`

The resulting `dist/` folder can be served by any static web server.

## Data

Workout status, lifting logs, conditioning logs, and the program start date are stored in the browser's localStorage. No account or backend is required.

## Included

- 14-day alternating A/B schedule
- Upper/lower strength sessions
- VO2max, threshold, and Zone 2 progression
- Calisthenics day
- Calendar
- Next-7-days view
- Workout completion / skip / undo
- Lifting and conditioning logs
- Progress charts
- Persistent local data
